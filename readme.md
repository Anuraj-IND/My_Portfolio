# 🛠️ Anuraj Maddheshiya — Interactive Skeuomorphic Portfolio

A beautifully crafted, premium, single-page portfolio website designed with a custom **skeuomorphic paper-and-cardboard/notebook aesthetic**. This portfolio is built entirely using vanilla technologies—featuring interactive 3D perspective parallax, hover-tilt physical feedback, and a highly responsive design.

---

## 🎨 Design & Aesthetic

The portfolio is built around a "board" containing "papers," "sticky notes," "tapes," "pins," and "polaroids."
* **Paper-and-Cardboard Theme:** Custom texture noise overlay and repeating-linear-gradient ruled lines to simulate physical lined notebook paper.
* **Interactive 3D Parallax:** A custom JavaScript-based parallax engine that shifts element depths relative to cursor movements in real-time, giving the page physical depth.
* **Hover Tilt Physics:** Sleek mouse-hover tilt transitions that rotate items dynamically in 3D space, responding to cursor entry coordinates.
* **Torn Edge & Pin Elements:** Custom SVG clip-paths to simulate torn paper edges, decorated with colorful pins and tapes.
* **Zero Frameworks:** Handcrafted with vanilla HTML, CSS, and JavaScript.

---

## 🚀 Key Features

* **Single-Page Application:** Quick loading and fluid scroll transitions.
* **Fully Responsive:** Smooth media-query break-points ranging from small mobile screens to massive desktop configurations.
* **Active Navigation Highlighting:** Real-time scroll observation to dynamically highlight the current active section in the navbar.
* **SEO Optimized:** Structured headings, clean semantic tags, and fast page load times.

## 🛠️ Getting Started & Local Development

Since this portfolio is built using vanilla web technologies, launching it locally is incredibly simple:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Anuraj-IND/My_Portfolio.git
   cd My_Portfolio
   ```

2. **Open with Live Server:**
   * Double-click `index.html` to open it in any web browser, OR
   * If using **VS Code**, install the **Live Server** extension, click **"Go Live"** in the status bar, and navigate to the local host address.
